# 🕹️ Autogaz

This started purely as a fun project, but after asking *"why should it stay on just one platform?"* it spiraled into this. I'm still keeping it updated! 🚀

---

## 📥 Download
You can find the builds for all supported platforms on the **[Releases](../../releases)** page!

---

## 🌍 How Far Did It Go? (Supported Platforms)

From the Atari 2600 to the PS4, Tizen to the Switch, and everything in between:

* **Consoles & Handhelds:** PS4, PS1, PSP, Nintendo Switch, Nintendo DS, GameCube, SNES, PS Vita, Sega Saturn
* **Retro Classics:** Atari 2600, Commodore 64 (C64)
* **Mobile & Modern:** Android, iOS, Tizen, Linux, Mac, Windows

---

## ⚠️ A Quick Note (Disclaimer)
I **don't own some of the devices** listed here, so I have to do development and testing via emulators. Theoretically, it should work on real hardware (99% chance), but I can't promise anything :/ If you get the chance to test it on a real device, let me know!

## 🎮 How Are the Controls?
The controls are pretty straightforward, to be honest. Usually, it's just one or two buttons. You'll figure it out as soon as you jump in, no lengthy manuals needed.
